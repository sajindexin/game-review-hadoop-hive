# 两层标签体系说明（通用主题 + 具体更新条目）

## 1. 为什么是两层

课程项目是"游戏更新反馈分析"。只看泛泛的情感（"内容正向/联机负向"）不够——
老师和同学真正想看的是"玩家对**姜岛探索**这个改动什么态度""新地图上线后有多少评论谈到"。

所以把标签拆成两层：

| 层 | 回答的问题 | 粒度 | 来源 | 数量 |
|---|---|---|---|---|
| 第一层 通用主题 | 玩家在聊什么方面、态度如何 | 粗 | 从评论原文归纳 | 11 类 |
| 第二层 具体更新条目 | 玩家在聊哪一条官方改动、态度如何 | 细 | 黄静雯分支官方 changelog | 75 项 |

两层是**泛化 ↔ 具体**关系，可叠加而非互斥。每个具体条目都归属一个通用主题（见第 3 节）。

## 2. 完整例子

评论："**姜岛探索**很好玩，但是**八人联机**老是掉线"

- 第一层（主题）：`level_design=positive`（姜岛属地图探索）+ `multiplayer=negative`（联机掉线）
- 第二层（条目）：`S15_01 姜岛探索=positive` + `S16_04 电脑端最多八人联机=negative`

一条评论、两个主题、两个条目、情感相反——这正是两层 ABSA 要处理的核心场景。

## 3. 条目 → 通用主题映射（75 项）

映射由 `code/build_item_taxonomy.py` 中的 `ITEM2ASPECT` 定义，依据每条官方条目的 description/section 语义人工归类：

| 通用主题 | 条目数 | 代表条目 |
|---|---|---|
| content 内容/玩法 | 36 | 姜岛探索、金核桃解锁、军备竞赛模式、颠覆计划任务 |
| level_design 地图/关卡 | 18 | 辐射镇回归、四角农场、火山地牢、对战地图扩展 |
| controls 操作/手感 | 7 | 攀树与藤蔓移动、盾牌重做、大师模式、先天技能 |
| monetization 付费/氪金 | 5 | 深渊物品包、丛林付费包、军械库通行证、夏季战绘箱 |
| graphics 画质/美术 | 3 | 海浪与水面改版、新发型、自定义着色器 |
| multiplayer 联机/服务器 | 3 | 本地分屏合作、八人联机、竞技场对战 |
| performance 性能/BUG | 2 | 服务器与传送带性能、手柄跳过片头崩溃修复 |
| story 剧情/叙事 | 1 | 配偶十四心事件 |

完整逐项映射见 `data/taxonomy/items_enriched.json` 的 `aspect` 字段。

## 4. 条目匹配：按 appid 约束（关键）

条目是**游戏特定**的——"姜岛"只属于星露谷，"军备竞赛"只属于 CS2。
如果全库匹配，"姜岛"可能被别的游戏评论里的偶然用词误命中。因此：

- 规则引擎 `item_matcher.match_items(clauses, appid)` 只在该 appid 的候选条目里匹配；
- RBT3 推理 `infer_rbt3_v2.py --appid` 只遍历该游戏的候选条目（`APPID_ITEMS`）；
- 已验证反例："姜岛探索很好玩"标为 CS2(appid=730) 时，条目层输出为空。

**匹配词** = 官方中文标题 + 中文别名 + 英文标题 + 英文别名（别名本身含繁体，如"薑島"）。
长词优先，且已剔除"连战/复战/挑战/地图"等高频歧义短词，避免误命中（精确率优先）。

## 5. 数据产物

- `data/taxonomy/items_enriched.json`：75 项条目（标题/描述/别名/appid/归属主题/匹配词）
- `data/taxonomy/patches.json`：26 个版本（含 window_start/end，前后各 14 天）
- `data/result/item_sentiment_detail.csv`：条目情感明细（评论 × 条目一行，含 patch_id、window_bucket）
- `data/result/item_distribution.csv`：条目 × 情感分布
- `data/result/item_patch_summary.csv`：条目 × 版本窗口统计

## 6. 与 RBT3 的对接

RBT3 用**同一套编码器、两种 prompt**（`train_rbt3_v2.py --task aspect|item`）：

- 主题层 prompt：`评价方面：内容玩法` + 评论 → 3 分类
- 条目层 prompt：`这条评论是否在讨论该游戏更新：姜岛探索。探索姜岛农场...` + 评论 → 3 分类

条目层用**配对分类**而非 75 类分类：75 项分属 12 游戏、每项样本极少，
直接做 75 类会严重长尾；配对分类让所有条目共享编码器，一条评论可命中多条更新，
且天然按 appid 约束候选集。详见 `docs/效果对比方案.md`。
