# 结果表字段说明

## 1. topic_sentiment_detail.csv（主题情感明细）

一条评论 × 一个主题 = 一行。共 535,623 行。

| 字段 | 类型 | 含义 |
|---|---|---|
| review_id | string | 评论唯一 ID |
| appid | string | 游戏 AppID |
| game_name | string | 游戏名 |
| created_date | string | 评论日期 YYYY-MM-DD（UTC）|
| game_version | string | 版本号（仅黑神话/GTA5 有值，其余为空）|
| aspect | string | 主题 ID（11 类之一，见标注规范）|
| name_zh | string | 主题中文名 |
| sentiment | string | positive / negative / neutral |
| confidence | double | 规则置信度 0~1 |
| sentiment_word | string | 命中的情感词（含"不"表示否定翻转）|
| evidence | string | 证据子句（原文片段，便于人工复核）|

## 2. topic_sentiment_review_summary.csv（评论级汇总）

一条评论一行。共 1,656,752 行。

| 字段 | 类型 | 含义 |
|---|---|---|
| review_id / appid / game_name / created_date / game_version | string | 同上 |
| voted_up | boolean | 整体是否推荐（来自原始数据）|
| n_aspects | int | 该评论命中的主题数 |
| pos_aspects | int | 其中正向主题数 |
| neg_aspects | int | 其中负向主题数 |
| primary_sentiment | string | 主导情感：负向主题多=negative，有正向=positive，否则 neutral/none |
| aspects_json | string | 该评论所有主题的 JSON 数组（含 evidence）|

## 3. topic_distribution.csv（主题分布统计）

每个主题 × 每种情感一行，共 33 行。供快速查看和 FineBI 绘图。

## 4. item_sentiment_detail.csv（条目情感明细 · 第二层）

一条评论 × 一个具体更新条目 = 一行。条目按 appid 约束匹配。

| 字段 | 类型 | 含义 |
|---|---|---|
| review_id / appid / game_name / created_date / game_version | string | 同上 |
| patch_id | string | 所属官方版本（来自黄静雯 patches.jsonl），空=评论不在任何版本窗口内 |
| window_bucket | string | pre_14d / release_day / post_14d / out_of_window |
| item_id | string | 官方更新条目 ID（75 项之一，如 S15_01）|
| item_title | string | 条目中文标题（如"姜岛探索"）|
| aspect | string | 该条目归属的通用主题（两层映射）|
| sentiment | string | positive / negative / neutral |
| confidence | double | 规则置信度（匹配词具体度 + 情感强度）|
| matched_term | string | 命中的官方别名（标题/中英别名，含繁体）|
| evidence | string | 证据子句 |

## 5. item_distribution.csv（条目分布统计）

每个条目 × 每种情感一行（仅保留命中数>0 的组合），按命中数降序。含 item_id/title/appid/game/aspect/sentiment/count。

## 6. item_patch_summary.csv（条目 × 版本窗口统计）

每个条目一行，列为 pre_14d / release_day / post_14d / out_of_window 各窗口的命中数，用于版本前后对比。

## 7. 字段与 Hive 表的对应

`sql/hive_metrics.sql` 的 part 0 已定义对应外部表：
- `nlp_topic.topic_sentiment_detail` ← topic_sentiment_detail.csv（第一层）
- `nlp_topic.topic_sentiment_review` ← topic_sentiment_review_summary.csv
- `nlp_topic.item_sentiment_detail` ← item_sentiment_detail.csv（第二层）
- `nlp_topic.item_dict` ← 75 项条目字典（由 items_enriched.json 导出）

导入示例（在 Hive 里）：
```sql
LOAD DATA LOCAL INPATH 'topic_sentiment_detail.csv' OVERWRITE INTO TABLE nlp_topic.topic_sentiment_detail;
LOAD DATA LOCAL INPATH 'item_sentiment_detail.csv' OVERWRITE INTO TABLE nlp_topic.item_sentiment_detail;
```

注意：CSV 带引号、首行为表头，导入前需按需处理表头行（Hive 默认会把表头当数据，可用 `tblproperties("skip.header.line.count"="1")`）。
