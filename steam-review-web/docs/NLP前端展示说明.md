# NLP 前端展示：11 类主题情感 + 75 项官方改动

页面入口：`nlp.html`（顶部导航「NLP 洞察」），也可从任一版本页的 **NLP 主题洞察** 按钮进入，
会自动带上该版本并预置「更新后 14 天」。

## 三项需求的落点

### 1. 展示 11 类通用主题的情感分布

页面第一屏用横向堆叠条形图展示 11 类主题，每根条由**正向 / 负向 / 中性**三段组成，
右侧列出四个数值与负向率：

| 主题 ID | 中文名 |
| --- | --- |
| `content` | 内容/玩法 |
| `level_design` | 地图/关卡设计 |
| `multiplayer` | 联机/服务器 |
| `graphics` | 画质/美术 |
| `performance` | 性能/优化/BUG |
| `story` | 剧情/叙事 |
| `controls` | 操作/手感/难度 |
| `monetization` | 付费/氪金 |
| `cheating` | 外挂/反作弊/公平 |
| `audio` | 音效/音乐 |
| `community` | 运营/社区/官方 |

支持两种排序：**提及量**（默认）、**负向率**。

> 负向率排序加了最小样本门槛：命中不足 10 条的主题一律排末位并标斜体
> （如星露谷 1.5 窗口内的「外挂/反作弊」只有 3 条，1 条负向就是 33%，不设门槛会误导）。

### 2. 支持按游戏、版本、语种、更新阶段筛选

| 维度 | 控件 | 说明 |
| --- | --- | --- |
| 游戏 | 下拉框 | 12 款；选中后版本下拉只显示该游戏的版本 |
| 版本 | 下拉框 | 26 个版本；不选则看**全时间线**（2010–2026） |
| 语种 | 中 / 英 / 全部 | 中英是两套独立规则词表分别标注的结果 |
| 更新阶段 | 更新前 14 天 / 发布当天 / 更新后 14 天 / 全部 | **仅在选定版本时可用**，因为阶段窗口依附于版本 |

筛选状态可深链：`nlp.html?patch=sdv_20201221_15&lang=zh&phase=after`

页面顶部实时显示「当前口径」，写清是哪个游戏、哪个版本、哪段窗口、哪个语种、命中多少条，
避免截图和报告里数字对不上。

### 3. 展示 75 项官方改动的正向、负向、中性反馈统计

第二屏是完整表格，75 项全部列出（含 45 项零命中的，灰色显示，不隐藏）：

| 列 | 含义 |
| --- | --- |
| 官方改动 | 条目中文名 + item_id |
| 游戏 / 版本 | 所属游戏、版本中文名、发布日期 |
| 正向 / 负向 / 中性 | 该条目被提及且判为该情感的评论数 |
| 合计 | 三者之和 |
| 窗口内 | 命中评论落在该条目所属版本前后 14 天窗口内的条数 |

支持按提及量、负向数、正向数排序；游戏、版本筛选与主题区联动。

## 数据来源

| 内容 | 来源文件 | 规模 |
| --- | --- | --- |
| 中文主题情感明细 | `topic_sentiment_detail.csv.gz` | 535,623 行 |
| 英文主题情感明细 | `topic_sentiment_detail_en.csv.gz` | 1,120,567 行 |
| 官方改动情感明细 | `item_sentiment_detail.csv` | 1,593 行（30 项有命中） |
| 主题中文名 | `topic_distribution.csv` | 11 类 |

导出后体积：`data/nlp/topics.js` + `data/nlp/items.js` 合计 **159 KB**。

## 关键口径（写报告时照抄）

**主题层**
- 一条评论可命中多个主题，因此「主题命中条数」大于评论数，两者不可直接相除。
- 全球面（不选版本）分别是中文 535,623 行 / 英文 1,120,567 行全量；
  某版本窗口只取落在该窗口内的评论（如星露谷 1.5 中文 91,262 行里的子集）。
- 中性占比天然偏高（全量约 59%）：规则标注要求命中情感词才判正/负，
  只提到主题但无明确褒贬的评论记为中性。

**改动层**
- 窗口按**条目自身所属版本**计算（`pre_14d / release_day / post_14d`），
  不按评论日期去猜同游戏的其它版本。
- 条目情感统计以中文为主：1,585 / 1,593 条为中文证据，英文仅 8 条，
  **因此条目的语种筛选不提供**（关闭而非给出不可靠结果）。
- 75 项里 30 项有评论命中，45 项为 0 —— 多数官方改动（尤其是内部修复）不会被玩家逐条点评，
  这是语料本身的特征，不是匹配失败。

## 复现导出

```bash
# 需要先拿到 NLP 模块的结果文件
git clone -b nlp-topic-sentiment --depth 1 --filter=blob:none --sparse \
  https://github.com/sajindexin/game-review-hadoop-hive.git nlp-src
cd nlp-src && git sparse-checkout set nlp-topic-sentiment/data/result nlp-topic-sentiment/data/taxonomy

# 回到项目根目录导出
python steam-review-web/tools/export_nlp_data.py \
  --nlp nlp-src/nlp-topic-sentiment \
  --patches repo/game-update-feedback-analysis/黄静雯_全组版本与改动 \
  --out steam-review-web/data/nlp
```

输出示例：

```
  zh: 535,623 行，落在版本窗口内 91,262 行
  en: 1,120,567 行，落在版本窗口内 45,365 行
  官方改动：75 项，其中有评论命中 30 项
完成：steam-review-web\data\nlp  合计 159 KB
```

## 已知限制

- 英文结果只覆盖英语，不含俄语、日语等其它语种（那部分评论在中文/英文词表里都不命中）。
- 星露谷 1.5 更新后中文窗口里「性能/优化/BUG」负向率 77%（87 条中 67 条负向），
  对应的是更新后闪退、箱子异常等具体 bug，不是"游戏变差"。
  解读时要结合 `patch.html` 的改动条目看。
- 主题分布图条形长度是**相对最大主题缩放**，不是绝对占比；绝对值看右侧数字列。
